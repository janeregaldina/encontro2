# Atividade – Testes Unitários e Integração

Repositório desenvolvido para a atividade prática da disciplina de **Tópicos Especiais em Engenharia de Software**, do curso de **Ciência da Computação da UEPB**.

## Objetivo

O objetivo desta atividade é aplicar conceitos de testes de software, utilizando testes unitários e de integração para verificar o funcionamento correto das funcionalidades implementadas.

---

## Tecnologias Utilizadas

* Node.js
* JavaScript
* Vitest
* Git
* GitHub

---

encontro2/

---

## Funcionalidades

### Classificação de Triângulos

O arquivo `triangle.js` contém a implementação da lógica de classificação de triângulos.

Os testes relacionados estão no arquivo:

```text
triangle.test.js
```

---

### Geração de Relatórios

O arquivo `report.js` contém a implementação das funcionalidades relacionadas à geração de relatórios.

Os testes relacionados estão no arquivo:

```text
report.test.js
```

---

## Instalação

Clone o repositório:

```bash
git clone https://github.com/janeregaldina/encontro2.git
```

Acesse a pasta do projeto:

```bash
cd encontro2
```

Instale as dependências:

```bash
npm install
```

---

## Execução dos Testes

Para executar os testes automatizados:

```bash
npm test
```
